# Git 자동 운영 원칙

## 사용자가 알아야 할 5가지

1. **처음 1번만**: GitHub 저장소 + 토큰 발급 (오늘 진행)
2. **자연어로 요청**: "커밋해줘", "돌려놔줘" — 명령어 안 외워도 됨
3. **다른 컴퓨터 작업 시**: `git clone https://github.com/best99582-del/richman.git`
4. **마무리 신호**: "오늘 작업 마무리하자" — 자동 push까지
5. **민감 정보**: `.gitignore`가 차단 중 (`trade_journal.xlsx` 등)

## 클로드 코드의 자동 git 책임

### 자동 커밋 트리거

- ✅ Phase 단계 완료
- ✅ 사용자 요청 작업 완료 (예: "수정해줘" 후)
- ✅ 기능 단위 변경 완료
- ✅ 사용자가 "마무리해줘" 요청

### 자동 안 하는 경우

- ❌ 코드 변경 없는 탐색/실험
- ❌ 사용자가 "커밋 하지 마"
- ❌ 새 종류의 파일이 추가될 때 (사용자에게 확인 후)

### 커밋 메시지 원칙

- 한국어로
- *왜* 변경했는지 적음 (무엇은 코드 보면 앎)
- 50자 이내 제목 + 필요시 본문

예시:
```
kelly: confidence_weight 1.5→2.0 (고확신 종목 비중 부족)
screener: ETF 제외 필터 추가
docs: phase_5 검증 결과 반영
```

## 시나리오 모음

### 작업 완료 시
```
사용자: "screener에 ETF 제외 추가해줘"
클로드: (수정 + 테스트 + 자동 commit + push)
       "✅ 커밋 a3b4c5d로 GitHub 반영"
```

### 되돌리기
```
사용자: "방금 거 돌려놔"
클로드: git checkout / revert 적절 선택
       "✅ 복원 완료"
```

### 하루 마무리
```
사용자: "오늘 마무리하자"
클로드: 미커밋 변경 점검 → 묶어서 커밋 → push
       "✅ 동기화 완료. 미커밋 0건"
```

### 다음 날 이어가기
```
사용자: "어제 어디까지 했지?"
클로드: git log로 어제 마지막 커밋 확인
       "어제 phase 5 검증까지 완료. 오늘은 phase 6부터"
```

## .gitignore 핵심 보호 항목

| 파일 | 이유 |
|---|---|
| `trade_journal.xlsx` | 실제 매매 기록 — 개인 자산 |
| `market_cap_cache.json` | 캐시 (재생성 가능, 크기 큼) |
| `alert_*.json` | 매매 전략 노출 위험 |
| `.env` | API 키 / 비밀번호 |
| `*_backup.py` | git이 백업 대신 |
| `korea_quant/` | 별개 프로젝트 |

## 만약 사용자가 직접 명령어 알고 싶다면

대부분 자연어로 요청하시면 되지만, 알아두면 좋은 것:

```powershell
git status              # 지금 상황
git log --oneline       # 이력 보기
git diff                # 변경 내용 보기
```

이외 명령은 클로드 코드에게 맡기시면 됩니다.
