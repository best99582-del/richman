## 3. 매수 조건 설정

### 3.1 조건식 구조

```
조건식 = 좌변 (팩터 + 함수 조합) | 연산자 | 우변 (숫자)

예시:
  순위내림차순({매출액성장률}) >= 100
  이동평균({종가}, {5일}) > {종가}
  비율내림차순('{분기자본}/{분기부채}') <= 50
  ({종가} + {시가}) / 2 >= 50000
```

- 좌변: 팩터 + 함수 + 사칙연산 (괄호로 우선순위 지정)
- 연산자: `>`, `>=`, `=`, `<=`, `<`
- 우변: 정수/실수만

### 3.2 사용 가능한 함수 14종

| 함수 | 의미 |
|---|---|
| 기본 | 팩터 원시값 그대로 |
| 과거값 | N일 전 값 |
| 이동평균 | N일 이동평균 |
| 비율 | 현재값 / 과거값 |
| 순위(오름차순) | 낮은 값일수록 높은 순위 |
| 순위(내림차순) | 높은 값일수록 높은 순위 |
| 최고값 | N일 중 최고값 |
| 최저값 | N일 중 최저값 |
| 변화량_기간 | 현재 - N일 전 |
| 변화율_기간 | (현재 - N일 전) / N일 전 |
| 절대값 | abs() |
| 기간총합 | N일 합산 |
| 비교 | 두 팩터 비교 |
| 표준편차 | N일 표준편차 |

### 3.3 팩터 카테고리 (400+ 개)

| 카테고리 | 예시 팩터 |
|---|---|
| 종합점수 | 종합점수 (메타 팩터) |
| 모멘텀 | 1/3/6/12개월 수익률, 상대강도 |
| 가격 | 종가, 시가, 고가, 저가, 거래량 |
| 수급 | 외국인 순매수, 기관 순매수, 거래대금 |
| 펀더멘탈 (성장) | 매출/영업이익/순이익 성장률 |
| 펀더멘탈 (가치) | PER, PBR, PSR, PCR, POR |
| 기술지표 | RSI, MACD, 볼린저밴드, 스토캐스틱 |
| 지수 | 코스피/코스닥 지수, 변화율 |
| 환율 | USD/KRW, EUR/KRW 등 |
| 금리 | 국고채 3년/10년, CD금리 |
| 마켓타이밍 | 코스피 PER, VKOSPI, 외국인 매매 비율 |

### 3.4 논리 조건식

- 작성 형태: `A AND B`, `A OR B`, `(A AND B) OR C`, `A AND (B OR C)`
- 조건식이 추가되면 알파벳 ID 자동 부여
- 검증 버튼 있음 (구문 오류 사전 체크)

### 3.5 매수 종목 선택 우선순위

- 정렬 기준 팩터 선택 (예: `{종합점수}`)
- 방향: "높은 값부터" / "낮은 값부터"
- 2차 우선순위 팩터 (tie-breaker)

## 4. 매수 비중 설정

| 항목 | 옵션 / 입력 | 우리 시스템 |
|---|---|---|
| 매수 비중 조절 방식 | 균등 비중 / ATR 비중 상한 / ATR 상대 비중 | `WEIGHT_METHOD` = equal/score/atr |
| 종목당 매수 비중 | % 입력 (예: 10%) | (TOP_N 기반 자동) |
| 최대 보유 종목 수 | 정수 입력 (예: 10종목) | `TOP_N` |
| 매수 대상 종목 수 | 최대 / 제한 | 미구현 |
| 종목당 최대 매수 금액 | 만원 입력 | 미구현 |
| 1일 최대 매수 종목 수 | 정수 입력 | 미구현 |

ATR 비중 상한: 개별 종목 비중 ≤ 1/TOP_N, ATR이 위험치 넘으면 비중 축소
ATR 상대 비중: 변동성 낮은 종목에 더 많은 비중 (Risk Parity)

## 5. 매수 방법 선택

| 방법 | 설명 |
|---|---|
| 일반 매수 | 설정 가격 기준 매수 |
| 분할 매수 | 나눠서 매수 |
| 돌파 매수 | 특정 가격 돌파 시 매수 |
| TWAP 매수 | 시간 분산 매수 |

### 매수 가격 기준 (드롭다운)
- 전일시초가 / 전일고가 / 전일저가 / 전일종가
- 당일시초가 / 당일종가
- 피벗 주가중심선 / 기준선 / 1차지지선 / 2차지지선 / 1차저항선 / 2차저항선
- 5일 / 10일 / 20일 / 60일 / 120일 / 200일 이동평균
- 수식입력 (자유 수식)

+ 추가 가격 조정 % 입력 (예: 전일종가 +0.5%)

### 추가 옵션
- 재매수 방지: 매도 후 N일간 동일 종목 매수 금지
- 매수 시간: HH:MM 시작 ~ HH:MM 종료 (틱 백테스트용)

## 7. 매도 조건

### 7.1 목표가 / 손절가
- 매도 주문 방법: 지정가 / 시장가
- 트레일링 스탑: 전 고점 대비 N% 하락 시 매도
- 목표가: 매수가 대비 +N% 상승 시 매도 (입력: 10%, 빠른 버튼 +1%/+5%/+10%/+30%)
- 손절가: 매수가 대비 -N% 하락 시 매도

### 7.2 보유 기간
- 최소 보유일: 이 기간은 무조건 보유 (조건 충족해도 매도 안 함)
- 최대 보유일: 이 기간 초과 시 강제 매도

### 7.3 조건 매도
- 매수 조건식과 동일한 방식의 조건식 작성
- 조건 충족 시 매도

### 7.4 종목 청산
- 보유 기간 초과 or 조건 도달 시 매도 실패해도 당일 강제 청산
- 청산 시점 설정 가능

### 7.5 매도 시간
- 특정 시간에만 매도 주문 (틱 백테스트용)

## 9. 우리 시스템 vs 젠포트 매핑표

## 10. 설계상 우리 시스템의 차별점

| 우리 시스템 | 젠포트와 다른 점 |
|---|---|
| TTM 명시적 명명 (PER_TTM, PSR_TTM 등) | 젠포트는 분기/연간/TTM 구분 불명확 |
| 팩터별 scoring 방식 독립 설정 | 젠포트는 함수 + 우선순위로 처리 |
| TTM 자동 역산 (분기 보고서 + DART thstrm_add_amount) | 젠포트는 자체 계산 (블랙박스) |
| CIS(포괄손익계산서) 자동 처리 | 젠포트는 사용자가 인지할 필요 없음 |
| 모든 설정이 단일 config.py 파일 | 젠포트는 GUI 입력 |
| Python 코드 베이스로 자유 확장 | 젠포트는 유료 클라우드 서비스 (월 단위 결제) |
