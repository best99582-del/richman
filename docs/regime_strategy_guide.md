# 📚 국면별 매매 전략 가이드 (수동 매매 참고용)

> **이 문서는 코드에서 제거된 GMM 국면 판별 기반 전략을 정리한 참고 자료입니다.**
> AI 시스템에는 더 이상 사용하지 않으며, 사용자가 직접 차트를 보고 수동으로 판단할 때 활용합니다.

---

## 국면 판별 방법 (직접 판단 기준)

### Bull (강세장) 판단 기준
- QQQ / SPY가 MA60 위에서 우상향 중
- 나스닥 일간 상승 종목 수 > 하락 종목 수 (Advance/Decline)
- MACD가 0선 위에서 우상향
- 실무 판단: "QQQ 차트 보기 → 60일 이동평균선 위에 있으면 강세장"

### Sideways (횡보장) 판단 기준
- QQQ가 MA20~MA60 사이에서 등락 반복
- ATR이 급증하거나 급감하지 않음 (일상적 변동)
- ADX 지표 < 25 (추세 강도 약함)
- 실무 판단: "1~2개월 차트 보기 → 박스권이면 횡보"

### Bear (조정/하락장) 판단 기준
- QQQ가 MA60 아래로 하락
- 연속 하락, 공포 뉴스 (금리 쇼크, 지정학 리스크 등)
- VIX > 25 이상 (변동성 지수 급등)
- 실무 판단: "QQQ가 200일 이동평균선 아래 → 하락장 경계"

## 국면별 매매 전략

### 🟢 Bull (강세장) — 추세 추종 전략

**원칙**: "추세가 이어지는 동안 최대한 길게 수익을 낸다."

**매수 조건**:
| 신호 | 기준 |
|------|------|
| BB 상단 돌파 + 스퀴즈 탈출 | BandWidth > 20일 평균 × 1.8배이면서 Close > 상단밴드 |
| RSI 매수 구간 (MA20 위) | 45 ≤ RSI ≤ 80이면서 Price > MA20 |
| MACD 골든크로스 보강 | 위 조건 충족 시 MACD 교차가 확인되면 확신도 강화 |

**매도 조건**:
| 신호 | 기준 |
|------|------|
| RSI 고점 이탈 | RSI가 80+ 찍고 70 아래로 하락 |
| 하단밴드 접근 + MACD 데드크로스 | Close < Lower × 1.05 동시에 MACD 데드크로스 |
| 약세 다이버전스 | 주가 상승 + RSI 하락 동시 발생 |

**적합 종목**: PLTR, IONQ, SOFI 등 성장 테마주의 강한 상승 구간

---

### 🟡 Sideways (횡보장) — 평균 회귀 전략

**원칙**: "박스권 하단에서 사고 상단에서 판다."

**매수 조건**:
| 신호 | 기준 |
|------|------|
| BB 하단 상향 돌파 | Close가 Lower를 아래→위로 뚫음 |
| Stoch 골든크로스 (과매도 영역) | Slow_K < 20이면서 골든크로스 |
| RSI 과매도 | RSI < 35 |

**매도 조건**:
| 신호 | 기준 |
|------|------|
| BB 상단 하향 돌파 | Close가 Upper를 위→아래로 뚫음 |
| Stoch 데드크로스 (과매수 영역) | Slow_K > 80이면서 데드크로스 |
| RSI 과매수 | RSI > 70 |

⚠️ **주의**: BB 스퀴즈 탈출 중이면 횡보 전략 중단 → 강세 전환 임박 신호.

**적합 구간**: 뉴스 없는 박스권 구간, 실적 발표 전 대기 구간

---

### 🔴 Bear (조정/하락장) — 방어적 단기 반등 전략

**원칙**: "공포에 사서 기술적 반등에 빠르게 판다. 오래 들고 있으면 안 된다."

**매수 조건**:
| 신호 | 기준 |
|------|------|
| 이격도 극단 침체 | Disparity(Close/MA20 비율) < 82% (종가 기준 MA20 대비 18% 이하) |
| 강세 다이버전스 | 주가 하락 + RSI 상승 동시 발생 |
| RSI 극단 과매도 | RSI < 20 (패닉 셀 구간) |

**매도 조건**:
| 신호 | 기준 |
|------|------|
| 이격도 과열 | Disparity > 105% (MA20 대비 5% 이상 위) |
| MACD 데드크로스 + MACD < 0 | 하락 모멘텀 재가속 |

**핵심 원칙**:
- 진입 비중 절반 이하 (50%)
- 목표 수익 3~5%에서 바로 청산 (반등이 완성되면 또 밀림)
- 절대 장기 보유 금지

## GMM 국면 판별 코드 (ta.py에 보존 중)

코드는 `ta.py`의 `Detect_Regime()` 함수에 그대로 남아 있습니다. 필요할 때 직접 호출 가능합니다.

```python
from ta import Make_Indicators, Detect_Regime
import FinanceDataReader as fdr

df = fdr.DataReader('QQQ', '2022-01-01')
df = Make_Indicators(df)
df = Detect_Regime(df)  # Regime_Name 컬럼 추가

# 최근 30일 국면 확인
print(df['Regime_Name'].tail(30).value_counts())
```

**GMM 설정** (참고):
- 피처: `Trend = (Close - MA60) / MA60`, `Vol = ATR / Close`
- 롤링 윈도우: 252일 (1년)
- 컴포넌트 수: 3 (Bull / Sideways / Bear)
- 프록시: QQQ (개별 소형주에 직접 적용 시 노이즈 多)

## 국면 판별 없이 매매할 때 대안 체크리스트

코드 시스템에서 국면 판별을 제거한 대신, 매매 전 아래를 수동으로 확인합니다.

```
□ QQQ가 MA60 위에 있는가? (강세장 기본 확인)
□ 종목의 RSI가 45~75 사이인가? (모멘텀 구간)
□ MACD가 양전환 또는 골든크로스인가?
□ BB 스퀴즈 탈출 중인가? (에너지 분출 임박)
□ 거래량이 평균 대비 1.5배 이상인가? (세력 참여 확인)
□ AI 확률이 52% 이상인가? (시스템 컨펌)
→ 위 6개 중 4개 이상 충족 시 매수 고려
```

## 주의사항

- 국면 판별은 **확증 편향**의 위험이 있음 — "내가 Bull이라고 판단했으니 하락은 일시적"이라는 착각
- 어떤 국면이든 **손절가는 반드시 설정** (트레일링 스탑 또는 ATR×1.5)
- 국면보다 **개별 종목의 기술적 셋업이 더 중요** — Bear 국면에서도 급등주는 나옴
