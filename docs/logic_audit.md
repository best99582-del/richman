```

  입력: 티커 리스트 → yfinance fast_info → JSON 캐시 (7일 유효)

  출력: ~800~1500개
  ↓

  입력: 위 결과 → 필터: 가격≥$5, 거래대금≥$20M, ATR 3~12%
  출력: ~15~30개
  ↓
screener.py ai_scanner() → _quick_analyze()
  입력: ~15~30개 → 로직: XGBoost 70/30 split, Precision≥0.55 → 출력: ~5~15개
  ↓

  입력: ~5~15개 → 로직: GMM국면 + 5-Fold CV + XGBoost → 출력: 확률순 랭킹

kelly.py Get_Position_Size()
  입력: AI확률 + 정밀도 + ATR
  로직: 손익비 2.0 고정 Half-Kelly (v10: 동적→고정)
  출력: 매수주수 / 손절가 / 투자비중
```

## 단계별 논리 분석

### [1] config.py — 파라미터 일관성

**달성하려는 것:**  
"변동성 3~10%인 나스닥 중소형주에서, 10일 내 10% 급등할 종목을 AI로 찾아, Half-Kelly로 자금을 배분한다."

**필요한 가정:**

| 파라미터 조합 | 암묵적 가정 |
|--------------|------------|
| `AI_TARGET_PCT=10`, `FORECAST_PERIOD=7` | 7일 내 10% 상승이 충분히 드문 이벤트여서 AI가 구별할 수 있다 |
| `SCREENER_MIN_VOLATILITY=3.0%` | ATR 3%+ 종목을 골랐으므로 일일 변동폭이 3% → 7일이면 정상 변동만으로 10% 도달 가능 |
| `ATR_STOP_MULTIPLIER=2.0` | 진입가 - ATR×2.0 = 약 6~24% 아래에 손절선 (v9.0: 1.5→2.0 상향) |
| `TRAILING_ATR_MULT=5.0` | 고점 - ATR×5.0 = 약 15~60% 아래에 트레일링 스탑 (v9.1: 3.5→5.0) |
| `WIN_LOSS_RATIO=2.0` | 켈리 공식 손익비 고정. 동적 손익비는 ATR 큰 종목에서 1.0 미만으로 떨어져 비중 0이 되는 문제 회피 (v10) |

**가정이 무너지는 조건:**

**🔴 핵심 모순: 타겟과 필터의 자기 충족 문제.**  
- 필터가 ATR 3%+ 종목을 고름 → 이 종목들은 일일 변동폭이 3~10%
- 10일 × 평균 3~5% 일일 변동 → 무작위 걸음만으로도 고가가 10% 이상 터치할 확률이 50~70%
- `AI_TARGET_PCT=10%`는 이 유니버스에서 "거의 항상 일어나는 일"을 타겟으로 학습
- AI가 "급등주를 발견"하는 게 아니라 "정상 변동을 급등으로 오분류"하게 됨

**🟡 손절선의 촘촘함.**  
- ATR×1.5 손절 = 약 4.5% 하락 시 청산. 타겟 종목의 일일 변동폭이 이미 3~10%
- 매수 다음날 정상 하락(-3~5%)만으로 손절 발동 가능
- 손절은 "비정상적 하락을 방어"해야 하는데, 정상 범위 안에서 작동

**치명도: 🔴**

### [2] screener.py — 1차 필터 논리

**달성하려는 것:**  
"유동성이 충분하고, 변동성이 살아있는 중소형주만 빠르게 걸러낸다."

**필요한 가정:**

| 필터 | 의도 | 가정 |
|------|------|------|
| 가격 ≥ $5 | 페니스톡 제거 | $5 이상이면 기관 투자 가능 종목 |
| 거래대금 ≥ $20M | 유동성 확보 (v10: 거래량→거래대금) | 슬리피지 없이 체결 가능, 저가주 투기성 자동 차단 |
| ATR 3~12% | 스윙 기회 확보 (v10: 10%→12%) | 변동성이 있어야 단기 수익 가능 |
| 시총 $1B~$20B | 중소형주 타겟 (v10: $3B→$1B, $50B→$20B) | 대형주 제외로 알파 기회 확보 |
| 업종 제외 (v10) | 금융/리츠/펀드 제거 | AI 모델 학습 패턴과 동학이 다른 자산군 분리 |

**가정이 무너지는 조건:**

**🟢 필터 자체는 논리적으로 건강.** 5개 필터를 동시에 통과하는 종목의 프로필:
- NASDAQ+NYSE, 시총 $1B~$20B, 주가 $5+, 일거래대금 $20M+, 일변동 3~12%, 비금융
- 실제 예시: IONQ, PLTR, SOFI, APLD, IREN 등 — 고성장 테마주/밈주 클러스터
- 이 종목들은 펀더멘탈보다 내러티브(AI, 양자컴, 크립토)에 의해 움직임
- 기술적 분석의 기본 가정("과거 패턴이 반복된다")이 내러티브 주도 종목에서는 약화

**치명도: 🟢** — 필터 자체는 합리적. 문제는 후속 단계와의 조합.

### [3] screener.py ai_scanner() — Light AI 논리

**달성하려는 것:**  
"많은 종목을 빠르게 훑어서, AI 학습이 가능한 종목만 predict.py로 보낸다."

**필요한 가정:**

| 설계 | 가정 |
|------|------|
| 70/30 시계열 split | "최근 30% 기간의 패턴이 미래를 대표한다" |
| `SCREENER_MIN_PRECISION=0.50` | "50% 이상 정밀도면 무작위보다 낫다" |
| 전체 데이터 재학습 후 예측 (L219~228) | "더 많은 데이터 = 더 좋은 모델" |

**가정이 무너지는 조건:**

**🟡 `MIN_PRECISION=0.50`의 무의미성.**
- [1]에서 분석했듯이 기저 양성비가 이미 50~70%
- 50% 정밀도는 기저 60% 대비 **동전 던지기보다 나쁜 것**
- 이 임계값은 "AI가 잘 맞추는 종목"이 아닌 "데이터가 충분한 종목"만 통과시킴
- **AI 성능 필터가 아닌 데이터 품질 필터로 기능**

**🟢 설계 의도의 정당성.**
- Light AI의 목적은 "정밀한 선별"이 아니라 "명백한 쓰레기 제거"
- 속도 최적화 관점에서는 올바른 설계

**치명도: 🟡**

### [4] predict.py Analyze_Full() — Deep AI 타겟 정의

**달성하려는 것:**  
"5-Fold 교차검증으로 모델 정밀도를 측정하고, 최종 모델이 오늘의 급등 확률을 예측한다."

**필요한 가정:**

| 설계 | 가정 |
|------|------|
| 타겟: `HIGH가 진입가 대비 10% 이상` (L79~80) | "고가 터치 = 실현 가능한 수익" |
| 피처 4개: RSI, Disparity, BandWidth, Volume_Ratio | "이 4개 지표가 급등의 충분한 선행 신호" |

**가정이 무너지는 조건:**

**🔴 타겟 정의의 구조적 낙관성 (가장 심각한 논리 오류).**

```python
# predict.py L79~80
after_highs = high_prices[i: i + forecast_period]
y.append(int(any((after_highs - before) / before * 100 >= target_pct)))
```

**문제 1: 고가는 팔 수 없다.**
- 장중 고가(High)는 그 순간에 매도 주문을 넣고 있어야만 실현 가능
- 실전에서는 "고가를 찍은 후 급락"이 빈번 → 종가 기준 수익은 훨씬 낮음

**문제 2: 진입가 기준의 불일치.**
- `before = close_prices[i-1]` → **어제 종가** 기준으로 10% 상승 판별
- 실제 매수는 오늘 시가에 이루어짐 → 갭업 시 이미 3~5% 위에서 진입

**문제 3: "any()" 함수의 관대함.**
- 10일 중 단 1일이라도 터치하면 양성 → 기간이 길수록 양성 비율 급증
- 변동성 3~10% 종목 × 10일 = 무작위 걸음으로도 60~70% 양성

**이 3가지가 결합되면:**
- AI는 매우 쉬운 문제를 학습 → 높은 정밀도(60~70%) → 하지만 실제 매매 수익은 보장되지 않음
- **"종목 추천이 잘 맞는다"는 경험은 이 낙관적 타겟 정의에서 기인할 가능성이 높음**

**치명도: 🔴**

### [5] ta.py Detect_Regime() — GMM 국면 판별

**달성하려는 것:**  
"QQQ의 Trend/Vol로 GMM 3클러스터를 학습하여 Bull/Sideways/Bear 판별."

**필요한 가정:**

| 설계 | 가정 |
|------|------|
| Trend = (Close - MA60) / MA60 | "MA60 대비 위치가 추세 방향을 나타냄" |
| 롤링 252일 윈도우 | "최근 1년이 오늘의 국면을 결정" |

**가정이 무너지는 조건:**

**🟡 후행성(Lagging) 문제.**
- MA60은 60일 평균 → 폭락이 시작되면 MA60은 아직 높음 → Trend가 급격히 음수로 전환
- 하지만 이미 폭락이 **진행 중**일 때 Bear로 전환 → "Bear 판별 = 바닥 근처"가 됨
- **Bear에서 수익률이 Bull보다 높은 역전 현상**의 코드상 원인이 바로 이것

**🟡 GMM 클러스터의 불안정성.**
- `warm_start=False` → 매번 완전 재학습 → 국면이 하루 만에 뒤집힐 수 있음

**치명도: 🟡** — 매매 필터로 쓰면 반등 기회를 체계적으로 놓침. 참고 지표로만 사용하면 무해.

### [6] kelly.py Get_Position_Size() — 자금 관리 논리

**달성하려는 것:**  
"기대값이 양수인 베팅에만 자금을 배분하되, 파산 위험을 극한까지 줄인다."

**필요한 가정:**

| 설계 | 가정 |
|------|------|
| `p = model_precision` | "모델 정밀도 = 이 매매의 승률" |
| `r = config.WIN_LOSS_RATIO = 2.0` | 손익비 고정 (v10: 동적→고정) |

**가정이 무너지는 조건:**

**🟡 `p`(승률)의 과대 추정** — [4]의 낙관적 타겟에서 정밀도가 부풀려짐.

**🟢 v10 손익비 고정의 trade-off.**
- 변경 전: 동적 손익비 = `target_profit / stop_risk`. ATR 큰 종목에서 r<1.0 → 켈리 비중 0 수렴 → 실용성 상실
- 변경 후: r=2.0 고정. ATR 무관하게 합리적 비중 산출
- 단점: ATR이 클수록 손절폭이 커지므로 r=2.0 가정이 실제와 어긋날 수 있음
- 보완: `MAX_WEIGHT_PER_TRADE=0.20` 캡이 단일 종목 위험 차단 → 입력 부정확성에 대한 1차 방어

**🟢 다중 방어 계층의 효과.**
- Half-Kelly(×0.5) + MAX_WEIGHT(20%) + SATELLITE(30%) = 최종 단일 종목 최대 **6%**
- 모델 정밀도 0.55 미만 → 켈리 음수 → 비중 0 (자동 차단)
- 이 정도면 입력이 부정확해도 파산 위험은 매우 낮음

**치명도: 🟢** — 가장 건강한 모듈. 입력 오류에 대한 내성이 높음.

## 핵심 논리 오류 TOP 3

### 🥇 1위: 타겟 정의의 구조적 낙관성 (predict.py L79~80)

"10일 내 고가가 10% 터치"를 양성으로 정의. 고변동주에서 기저 양성비 60~70% → AI가 이길 기저선이 너무 높음. 동시에 고가 터치 ≠ 실현 수익. 높은 정밀도가 실제 돈으로 이어지지 않음. **전체 파이프라인의 신뢰도가 이 한 지점에 의존.**

### 🥈 2위: 필터와 타겟의 자기 충족 (config.py 파라미터 조합)

"변동성 3%+ 종목을 골라놓고 10일 내 10% 상승을 예측"하는 것은, "키 180cm 이상인 사람을 모아놓고 키가 큰 사람을 예측"하는 것과 같음. 필터가 이미 답을 결정함.

### 🥉 3위: GMM 국면 판별의 후행성 (ta.py Detect_Regime)

MA60 기반 Trend가 60일 후행 → Bear 판별 시점이 이미 바닥 근처. Bear에서 매수를 차단하면 반등 기회를 체계적으로 놓침.

## 논리적으로 가장 건강한 부분 TOP 3

### 🥇 1위: Kelly 자금 관리 (kelly.py)

ATR → 손익비 → Kelly → Half → Max Cap → Satellite 배분. 변동성이 크면 비중을 줄이고, 작으면 늘리는 음의 피드백 루프가 정확히 작동. 3중 안전장치로 입력 오류에 대한 내성이 높음.

### 🥈 2위: Screener 2단계 파이프라인 아키텍처

Light AI(빠르게 거르기) → Deep AI(정밀 분석) 분리는 실전 퀀트의 표준. 데이터 재다운로드 방지, 에러 핸들링 등 운영 품질이 높음.

### 🥉 3위: Walk-Forward AI 신호 부착 (predict.py Add_AI_Signals)

`train_end = i - FORECAST_PERIOD`로 미래 참조 완벽 차단. Laplace 스무딩 정밀도. backtest용 AI 신호가 lookahead-free로 올바르게 구현됨.

## 사용자에게 한 줄 결론

> **이 시스템이 종목 추천에서 좋은 결과를 내는 것은, AI가 급등을 예측해서가 아니라 "변동성이 높은 종목을 골라놓으면 10일 내 고가가 10% 이상 터치할 확률이 원래 60~70%"이기 때문입니다. 시스템의 진짜 가치는 자금 관리(Kelly)와 파이프라인 아키텍처에 있으며, AI의 예측력을 살리려면 타겟 정의를 "고가 터치 10%"에서 "종가 기준 3~5% 상승"으로 바꿔야 합니다.**
